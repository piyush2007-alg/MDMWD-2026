# MDMWD 2026

This folder contains a collection of front-end web development practicals created using HTML, CSS, Tailwind CSS, and JavaScript. The work shows the learning journey from basic page structure and form design to interactive UI components and task management dashboards.

## Project Objective

The project is designed for a Modern Web Development course. It helps students practice:

- HTML structure and semantic tags
- CSS styling and layout design
- Tailwind utility classes
- JavaScript interactivity
- Responsive webpage design
- Form handling and validation
- Browser local storage for app data persistence

## Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Font Awesome icons
- Local browser storage

## Folder Structure

## Practical Analysis

### 1. webpages/Practical_1.html
Focus: Basic HTML page structure and academic/form-based layout.

This practical introduces the fundamentals of creating web pages with headings, forms, tables, controls, and input elements. It demonstrates how HTML is used to organize content and collect user input in a structured way.

### 2. webpages/Practical_2.html
Focus: Detailed enrollment form and data collection page.

This practical is a stronger form design exercise. It includes multiple fields such as personal details, contact information, academic data, guardian information, and radio/checkbox inputs. It helps students learn how to structure forms for real-world applications.

### 3. Practical_3.html
Focus: Event landing page design.

This page promotes TECHNOSTAV 2026 with a colorful festival-style design, hero section, feature cards, and a registration form. It teaches promotional design, spacing, colors, and UI hierarchy.

### 4. Practical_4.html
Focus: E-commerce category page.

This page mimics a Myntra-style product showcase with a navigation bar, filters, product cards, wishlist/cart actions, and responsive layout. It emphasizes product listing UX and modern shopping interface design.

### 5. Practical_5.html
Focus: Restaurant menu website.

This practical includes a sticky header, menu cards, pricing badges, CTA buttons, and food imagery. It helps students learn how to create visually rich landing pages for businesses.

### 6. Practical_6.html
Focus: Interactive grade calculator.

This is one of the first JavaScript-based practicals. It calculates total marks, percentage, and final grade based on student inputs and shows responsive result output on the page. It introduces the logic behind user interaction and calculations in the browser.

### 7. Practical_7.html
Focus: FAQ/accordion style page.

This practical teaches collapsible content using JavaScript. Each question expands and collapses its answer, demonstrating interactive UI behavior with simple DOM manipulation.

### 8. Practical_8.html
Focus: Student registration form with validation and modern design.

This practical is a polished registration interface with modern card layout, form validation, error messages, and a success state. It is a strong example of frontend validation and user experience.

### 9. Practical_9.html
Focus: Student task manager dashboard.

This is the most advanced practical in the project. It includes:

- Add, edit, and delete tasks
- Search and sorting
- Category and status filters
- Theme toggle for light/dark mode
- Progress dashboard with task stats
- Local storage persistence

This practical demonstrates a complete front-end application with real user interaction and state management logic.
